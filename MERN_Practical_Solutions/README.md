# MERN / Express Practical Solutions
Beginner-friendly separate practicals. Install Node.js and MongoDB for Mongo/MERN tasks.
Each folder has its own `package.json`; run `npm install`, then `npm start`.
Redis is intentionally not used. Q3 uses the same file-based session approach as Q2.
For mail in Q4, configure SMTP values in environment variables; never commit real credentials.
